# Customer Segmentation & Prediction System

## 📌 Description
This project analyzes customer data and segments them into groups using K-Means, then predicts customer category using Machine Learning.

## 🎯 Objectives
- Understand customer behavior
- Segment customers into groups
- Predict customer category

## 🧠 Methods
- Data Analysis
- Data Visualization
- K-Means Clustering
- Random Forest Classification

## 📊 Results
Customers were divided into 3 groups based on income and spending behavior.
The prediction model achieved good accuracy.

## 🛠 Tools Used
- Python
- Pandas
- Seaborn
- Scikit-learn

## 🚀 Conclusion
This project helps businesses understand their customers and improve marketing strategies.
